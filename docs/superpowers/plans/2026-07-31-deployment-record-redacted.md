# Site deployment record removed

The former deployment plan described a real installation and was removed from the tracked tree
under [Decisions Register R61](../../decisions-register.md#r61--site-specific-operational-records-never-enter-this-repository--2026-08-02).
Replacing names with placeholders is not sufficient when a document still preserves a site's
topology, inventory, progress, backup posture, or accepted weaknesses.

Use the generic [Ubuntu server installation runbook](../../runbooks/install-ubuntu-server.md) for
product procedures. Concrete deployment worksheets, evidence, deviations, and risk acceptances
belong in the organization's controlled operational documentation. Do not reconstruct a site
dossier in this repository.
